## Narration (one Ogg Vorbis file per chapter, kept in `narration/`)

The narration is the public-domain H. P. Paull translation of Hans Christian Andersen's The Little Match-Seller (the text is word for word the tale stored by the app),
spoken by offline speech synthesis: eSpeak NG (voice en-us+f2) rendered to WAV on the build machine and encoded with oggenc (Vorbis, quality 2).
No recording, sample library or network service was used; the files are original works of this product (licence `original`). Source of each file:

| File | Source | Licence |
|---|---|---|
| narration/alley.ogg | eSpeak NG offline synthesis of the public-domain tale text for the alley chapter | original |
| narration/goose.ogg | eSpeak NG offline synthesis of the public-domain tale text for the goose chapter | original |
| narration/grandmother.ogg | eSpeak NG offline synthesis of the public-domain tale text for the grandmother chapter | original |
| narration/shelf.ogg | eSpeak NG offline synthesis of the public-domain tale text for the shelf chapter | original |
| narration/star.ogg | eSpeak NG offline synthesis of the public-domain tale text for the star chapter | original |
| narration/stove.ogg | eSpeak NG offline synthesis of the public-domain tale text for the stove chapter | original |
| narration/tree.ogg | eSpeak NG offline synthesis of the public-domain tale text for the tree chapter | original |

## Geometry, textures, icons

All 3D geometry, textures, snow, flames and the chapter stills are generated in code (three.js primitives, canvas and SVG); no model, image or sound is fetched at run time.
