## Fonts

Both typefaces are bundled with the app as self-hosted variable woff2 files (`client/fonts`), taken from the Fontsource packages `@fontsource-variable/hubot-sans` and `@fontsource-variable/mona-sans` at version 5.3.0. See `assets.json` for each file's hash and source.

- Hubot Sans: Copyright 2021 The Hubot Sans Project Authors (https://github.com/github/hubot-sans), with Reserved Font Name "Hubot". Licence: SIL Open Font License 1.1 (OFL-1.1).
- Mona Sans: Copyright 2022 The Mona Sans Project Authors (https://github.com/github/mona-sans), with Reserved Font Name "Mona". Licence: SIL Open Font License 1.1 (OFL-1.1).
