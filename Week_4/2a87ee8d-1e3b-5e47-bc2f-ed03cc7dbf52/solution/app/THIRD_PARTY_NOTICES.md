# Third-party notices

Lanternfold Rooms ships the packages, fonts and icons below. Shipped packages are the production dependency
tree (`npm ls --omit=dev --all`); build tools follow. No other media is bundled: the dot grid, stickies
and cursor glyph are drawn in CSS and SVG, and the hero mesh (client/mesh.png) is an image drawn for this app (original).
