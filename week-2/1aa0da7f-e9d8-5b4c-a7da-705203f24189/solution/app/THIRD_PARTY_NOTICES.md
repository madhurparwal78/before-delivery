# Third-party notices

Everything Wardline ships that it did not write. No browser library is bundled: the interface is hand-written, its icons are inline SVG paths drawn for this app in the Lucide style (`original`), and the seed exhibits are generated by the app's own code (`original`). Build and runtime dependencies are the same list: there is no build tool beyond Python's `compileall`.
